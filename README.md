# Каталог Кондиционеров Сочи

Этот проект создан с использованием React, TypeScript и Vite.

## Инструкция по публикации (для MaxArts1)

### 1. Подготовка
Откройте терминал в папке проекта. Если вы еще не делали этого, выполните:
```bash
npm install
```

### 2. Отправка кода и Деплой
Выполните эту команду, чтобы собрать сайт и отправить его в интернет:
```bash
npm run deploy
```
*Дождитесь сообщения "Published" в терминале.*

### 3. 🔴 ВАЖНО: Настройка GitHub (Если видите ошибку 404)
Если вы видите надпись **"Здесь нет сайта GitHub Pages"** (404), значит GitHub не знает, какую ветку показывать.

1. Зайдите в репозиторий на GitHub: **Settings (Настройки)** -> **Pages**.
2. В разделе **Build and deployment** -> **Branch**:
   - Выберите ветку **`gh-pages`** (это важно! не main).
   - Нажмите **Save**.
3. Подождите 1-2 минуты и обновите страницу сайта.
