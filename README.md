# Каталог Кондиционеров Сочи

Этот проект создан с использованием React, TypeScript и Vite.

## Инструкция по публикации (для MaxArts1)

1.  **Создайте репозиторий** на GitHub с именем **`sochi-ac`** (пустой, без README/gitignore).

2.  Откройте терминал в папке с проектом и выполните эти команды по очереди:

    ```bash
    # Инициализация
    git init
    git add .
    git commit -m "Запуск сайта Кондиционеры Сочи"
    
    # Привязка к вашему GitHub
    git branch -M main
    git remote add origin https://github.com/MaxArts1/sochi-ac.git
    
    # Отправка кода
    git push -u origin main
    ```

3.  **Публикация сайта**:
    После того как код отправлен, выполните команду для деплоя:

    ```bash
    npm run deploy
    ```

4.  **Готово!**
    Через пару минут ваш сайт будет доступен по адресу:
    👉 **https://MaxArts1.github.io/sochi-ac/**
