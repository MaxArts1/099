# Каталог Кондиционеров Сочи

Этот проект создан с использованием React, TypeScript и Vite.

## 🚀 Как обновить сайт (Инструкция)

Если сайт не открывается, выполните эти шаги по порядку.

### 1. Отправка обновлений
В терминале введите:
```bash
npm run deploy
```
Дождитесь сообщения **"Published"**.

### 2. ⚙️ Самый важный шаг (Настройка GitHub)
Если вы видите ошибку 404 или белый экран:

1. Откройте страницу вашего репозитория на GitHub.
2. Перейдите в **Settings** (Настройки) -> **Pages** (в меню слева).
3. В разделе **Branch** убедитесь, что выбрано:
   - Ветка: **gh-pages** (ОБЯЗАТЕЛЬНО!)
   - Папка: **/(root)**
4. Нажмите **Save**.
