# ⚡ SuperMaster — MVP маркетплейс услуг

Платформа, где заказчики находят мастеров (ремонт, электрика, сантехника, уборка,
сборка мебели, бытовая техника), бронируют услугу и оплачивают заказ онлайн.

**Stack:** Node.js (встроенные `node:http` + `node:sqlite`), чистые HTML/CSS/JS.
**Zero-dependency** — нужен только Node.js ≥ 22.5, никаких `npm install`.

## Быстрый старт

```bash
cd supermaster
node server.js
```

Откройте в браузере: **http://127.0.0.1:3000**

Переменные окружения:

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3000` | Порт сервера |
| `HOST` | `127.0.0.1` | Адрес прослушивания (для доступа с других устройств: `HOST=0.0.0.0`) |
| `NEWAPI_IDP` | см. `config.json` | IDP партнёрского API лидов |
| `NEWAPI_OFFER_ID` | — | ИД оффера (если не задан `direction_id`) |
| `NEWAPI_DIRECTION_ID` | — | ИД направления (если не задан `offer_id`) |
| `NEWAPI_BRANCH_ID` | `0` | ИД филиала |
| `NEWAPI_IS_PM` | `false` | `true` = частный мастер |
| `NEWAPI_ENABLED` | `true` | `false` — выключить отправку лидов |
| `NEWAPI_TIMEOUT` | `8000` | Таймаут запроса к API, мс |

База данных создаётся автоматически при первом запуске (`data/supermaster.db`)
и заполняется демо-данными: 7 мастеров, 16 услуг, 6 категорий.

## Интеграция с API лидов (gate.newapi.ru)

При каждом бронировании заказ автоматически отправляется в партнёрский API
методом `lead` (`POST https://gate.newapi.ru/lead?source=partner&idp=...`).

Настройки — файл `data/config.json` (или env-переменные `NEWAPI_*`):

```json
{
  "idp": "2e65798c-9ae4-96c7-00537a5c29dd9cdc",
  "offer_id": null,
  "direction_id": null,
  "branch_id": 0,
  "is_pm": false,
  "source": "partner",
  "enabled": true,
  "lead_timeout_ms": 8000
}
```

**Важно:** задайте `offer_id` **или** `direction_id` (и при необходимости `branch_id`) —
без них лиды отправляться не будут (в заказе появится статус «Отправка лида не настроена»).

### Справочник городов

Файл `data/cities.json` — клиент **обязательно выбирает город** при бронировании
(поле появляется в форме, когда в справочнике есть хотя бы один город):

```json
[
  { "id": 1, "name": "Москва", "branch_id": 0 },
  { "id": 2, "name": "Санкт-Петербург", "branch_id": 0 }
]
```

- `id` — ИД города из справочника API (`city_id` в лиде)
- `branch_id` — необязателен: если задан у города, уходит в лид вместо `branch_id` из `config.json`
- `name` — показывается клиенту и в карточке заказа

Маппинг полей заказа → лида:

| Заказ (SuperMaster) | Поле лида |
|---|---|
| `customer_name` | `name` |
| `customer_phone` | `phones[0]` |
| город из формы | `city_id` + `branch_id` (города или конфига) |
| `comment` + услуга + мастер | `description` |
| `date` | `date` |
| `time` (например `10:00`) | `hour_from=10`, `hour_to=11` |
| — | `comment` = «SuperMaster MVP · заказ №N» |
| — | `sub_id1=supermaster-mvp`, `utm_source=supermaster` |

Коды ответа API: `204` — лид принят, `202` — дубль, `400` — ошибка данных.
Статус отправки каждого заказа виден в разделе «Мои заказы» (и в поле `lead_status` в API).
Ошибки интеграции никогда не блокируют заказ в SuperMaster: заказ всегда создаётся,
а статус лида пишется отдельно.

## Возможности MVP

- 🔍 **Каталог услуг** — фильтр по категориям и поиск
- 👷 **Профили мастеров** — рейтинг, отзывы, опыт, список услуг, цены «от»
- 📅 **Бронирование** — выбор даты и времени, контакты клиента, комментарий
- 💳 **Оплата** — симуляция оплаты заказа одной кнопкой
- 📋 **Мои заказы** — статусы и жизненный цикл:
  `Новый → Оплачен → Подтверждён мастером → Выполнен` (или `Отменён`)
- 📱 Адаптивная вёрстка, работает на телефоне

## REST API

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/categories` | Категории с количеством услуг |
| `GET` | `/api/services?category=&q=` | Услуги (фильтр по категории/поиску) |
| `GET` | `/api/services/:id` | Детали услуги |
| `GET` | `/api/masters` | Все мастера |
| `GET` | `/api/masters/:id` | Профиль мастера с его услугами |
| `POST` | `/api/orders` | Создать заказ `{service_id, customer_name, customer_phone, date, time, comment}` |
| `GET` | `/api/orders` | Все заказы |
| `POST` | `/api/orders/:id/pay` | Оплатить заказ (new → paid) |
| `PATCH` | `/api/orders/:id` | Смена статуса `{status: confirmed|done|cancelled}` |
